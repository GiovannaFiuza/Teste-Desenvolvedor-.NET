# Teste Desenvolvedor .NET

![Aiko](imagens/logocrm.png)



Este projeto é uma API desenvolvida com **ASP.NET Core (.NET 8)** com endpoints para realizar operações de **CRUD** (Create, Read, Update, Delete) para um **vestibular**, utilizando **Entity Framework Core** para acesso a dados e **SQL Server** como banco de dados.
A documentação e testes da API foram feitas através do **Swagger**.
